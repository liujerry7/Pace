Pace

What are we building?

Tap the mic and talk. Claude answers out loud and builds what you ask for: in files kept in this browser (the folder icon above), or in your GitHub repo once one is connected in Settings.

    Settings

    Claude

    Saved only in this browser and sent only to api.anthropic.com. Without a key, Pace just transcribes.

    Voice

    Sounds robotic? In Chrome the “Google” voices sound best, in Edge the “Natural” ones. On iPhone, download an Enhanced or Premium voice in Settings → Accessibility → Spoken Content → Voices → English, then pick it here. Each device has its own voices.

    GitHub repo · optional

    Lets Claude read your repo and commit changes to a work branch (created from the default branch if needed), never straight to your default branch. Use a fine-grained token with Contents: Read and write on just the repos you want. Sent only to api.github.com.

    Other repos Claude may change in the same chat, such as the engine your game uses. Separate them with commas. The token needs access to each.

    Lifeline · optional

    Lets Claude check your schedule, projects and to-dos, and log time, through Lifeline's MCP server. Anthropic's servers make the calls, so the server must be reachable over the internet (HTTPS). The token is sent only to api.anthropic.com, which passes it to that server.

    Coding conventions

    Claude follows these in code it writes and suggests them when you ask for something that breaks them. A repo's own CLAUDE.md, CONVENTIONS.md or .clang-format wins. Copied from your Lifeline docs.

    Passcode lock · optional

    Encrypts your saved key and tokens in this browser. Pace asks for the passcode when it opens, and again after 15 minutes in the background. Use 6+ characters; a few words is strongest. There's no recovery: if you forget it, erase and paste your keys again.

    Other devices

    Copy this setup (keys, repo and settings) to your phone with a QR code. The keys travel encrypted, unlocked by a one-time code shown next to the QR.

    Files

    A repo is connected, so Claude is working in GitHub. These files stay in this browser.
