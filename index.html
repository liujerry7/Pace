    Claude

    Saved only in this browser and sent only to api.anthropic.com. Without a key, Pace just transcribes.

    GitHub repo · optional

    Lets Claude read your repo and commit changes to a work branch (created from the default branch if needed), never straight to your default branch. Use a fine-grained token with Contents: Read and write on just the repos you want. Sent only to api.github.com.

    Coding conventions

    Claude follows these in code it writes and suggests them when you ask for something that breaks them. A repo's own CLAUDE.md, CONVENTIONS.md or .clang-format wins. Copied from your Lifeline docs.

    Passcode lock · optional

    Encrypts your saved key and token in this browser. Pace asks for the passcode when it opens, and again after 15 minutes in the background. Use 6+ characters; a few words is strongest. There's no recovery: if you forget it, erase and paste your keys again.
