    Claude

    Saved only in this browser and sent only to api.anthropic.com. Without a key, Pace just transcribes.

    GitHub repo · optional

    Lets Claude read your repo and commit changes to a work branch (created from the default branch if needed), never straight to your default branch. Use a fine-grained token for just this repo with Contents: Read and write. Sent only to api.github.com.

    Passcode lock · optional

    Encrypts your saved key and token in this browser. Pace asks for the passcode each time it opens.
