# Voice Code

Version one of a voice coding tool: hold a button, speak, and each phrase becomes a numbered line.
Single `index.html`, no build step, no dependencies. Uses the Web Speech API, so it works best in Chrome.

## Open it
- **Laptop:** open `index.html` in Chrome (double-click it, or drag it into a Chrome window). Allow the microphone when asked.
- **Phone:** use the GitHub Pages URL (HTTPS is required for the microphone).

## GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → pick the branch that holds `index.html`, folder `/ (root)` → Save.
After about a minute the site is at `https://<your-username>.github.io/<repo-name>/`.
